# Mailtarn

**Where test emails land safely.**

Mailtarn catches every email your app sends from dev, staging and CI, so nothing reaches a real inbox. Point your app's SMTP settings at Mailtarn. No code changes.

**Coming in the first release**
- Inspect HTML, plain text, headers, raw source and attachments
- Full-text search, plus shareable links to a single message
- A REST API and "wait for a message" to check emails in your automated tests
